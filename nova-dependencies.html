各模块核心功能详表

模块层核心职责关键导出 / API关键文件
runtime 叶子 L0 运行时地基：settings 加载/校验、会话存储、结构化日志、路径规范化与越权防护。所有可配置项的 zod schema 单一来源。 settingsSchema · loadSettings/parseSettings/saveSettings · isDangerousBash · canonicalizePath/canonicalizeRoots · createSession/listSessions/getSession · createLogger · mcpServerSchema · Transcript · computeCost/formatMoney · SlashCommand（类型契约） config.ts · models.ts · session.ts · path-safety.ts · logging.ts · prompt-expansion.ts · slash-types.ts · transcript.ts · cost.ts
core 叶子 L0 与模型无关的 agent 主循环 + hook 体系 + 模型客户端抽象。唯一扩展点是 HookRegistry；含 DeepSeek 专属错误翻译/重试与 thinking 预算。 agentLoop/LoopResult/LoopTerminatedError · HookRegistry/HookPoint/HookDecision · createAnthropicModel/ModelClient/ModelRequest · resolveBudget/THINKING_BUDGETS · decide(StopDecision) · ProviderError/PROVIDERS · FileAccessLedger/InvariantsCheck/SandboxBridge（不透明契约） loop.ts · hooks.ts · model.ts · messages.ts · thinking.ts · stop-reason.ts · retry.ts · providers/
safety L1 三道闸门合一：权限引擎对每次工具调用做 allow / deny / ask；invariants 做 read-before-edit 与 mtime 漂移校验，防止覆盖没读过的内容；sandbox 把子进程写入锁在工作区。三者共用 runtime 的 canonicalizePath，对「同一个文件」的判定一致。 PermissionEngine · PermissionDecision/PermissionEffect/PermissionInput · isWithin · createInvariants/InMemoryFileAccessLedger · createSandbox/SandboxControl permission.ts · invariants.ts · sandbox.ts
tools L1 内置工具集 + 注册表 + 派发器。dispatcher 用 zod 预校验输入，parse 错误转成 is_error 结果，并把归一化后的输入交给闸门与 run。是除 core/runtime 外唯一额外依赖 lsp 的包（type-only）；刻意不依赖 safety —— 闸门只以 core 的 InvariantsCheck 接口注入。 ToolRegistry · createDispatcher · withAliases/PATH_ALIASES · bash/read/edit/write/glob/grep/lsp/webfetch/websearch/ask-user · todo·task·cron 工具组 · background/monitor 长时命令 · skills/load-skill dispatcher.ts · registry.ts · schema.ts · 各工具平铺于 src/ · todo/ task/ cron/ background/ monitor/
lsp 叶子 L0 代码智能：派生/多路复用语言服务器（LSP），向 lsp 工具与 /lsp 命令提供 hover、诊断、文档/工作区符号、定义跳转。被 tools 以 type-only 方式消费。 LspManager · 服务器配置/解析 · diagnostics/hover/symbols/definition 类型 manager.ts · client.ts · rpc.ts · servers.ts · types.ts
mcp L1 MCP 服务接入：stdio / HTTP / SSE 传输、OAuth 流程、工具名前缀映射（mcp__<server>__<tool>）、prompt 与 resource 桥接。 McpManager/transportForSpec · mcpToolToHandler/MCP_TOOL_PREFIX · mcpPromptToSlash · resourceToolHandlers · createNovaOAuthProvider client.ts · stdio.ts · http.ts · oauth.ts · tool.ts · prompt.ts · resource.ts
agent L2 把 core loop 与默认 hooks（权限、压缩、transcript、持久化）组装成可用 agent；构建系统提示词；按游标增量持久化 messages.jsonl。同时收纳记忆 bundle 加载与压缩（原 context 包），以及子 agent 的 Task 工具与定义加载（原 subagent 包）。 createAgent/Agent/agent.on(point,fn) · TurnResult · buildSystemPrompt · persistMessages/loadMessages/emptyCursor · loadMemory/MemoryBundle · autoCompact/sliceFromLastCompacted · createSubAgentTool/AgentRegistry/loadAgentDefinitions agent.ts · system-prompt.ts · persistence.ts · memory.ts · compact.ts · subagent.ts · subagent-system-prompt.ts · definitions.ts · loader.ts
cli App 唯一 active app：终端 REPL，组装全部 7 个包，把 model/tools/permissions/sandbox/hooks/lsp 全部连线，是 nova 二进制入口。slash 命令注册表与 .md 加载器也在这里（类型契约在 runtime）。 repl 主循环 · context 装配 · slash-registry · 命令/快捷键 · 流式渲染 apps/cli/src/repl.ts · context.ts · slash-registry.ts
