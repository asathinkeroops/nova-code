各模块核心功能详表

模块层核心职责关键导出 / API关键文件
runtime 叶子 L0 运行时地基：settings 加载/校验、会话存储、结构化日志、路径规范化与越权防护。所有可配置项的 zod schema 单一来源。 settingsSchema · loadSettings/parseSettings/saveSettings · isDangerousBash · canonicalizePath/canonicalizeRoots · createSession/listSessions/getSession · createLogger · mcpServerSchema config.ts · session.ts · path-safety.ts · logging.ts
core 叶子 L0 与模型无关的 agent 主循环 + hook 体系 + 模型客户端抽象。唯一扩展点是 HookRegistry；含 DeepSeek 专属错误翻译/重试与 thinking 预算。 agentLoop/LoopResult/LoopTerminatedError · HookRegistry/HookPoint/HookDecision · createAnthropicModel/ModelClient/ModelRequest · resolveBudget/THINKING_BUDGETS · decide(StopDecision) · translateDeepSeekError/DeepSeekApiError loop.ts · hooks.ts · model.ts · messages.ts · thinking.ts · stop-reason.ts · deepseek-errors.ts
observability 叶子 L0 旁路观测：把 hook 事件与历史落盘成 transcript（JSONL），并提供指标、成本核算、eval 回放支撑。不参与决策。 Transcript · TranscriptKind · TranscriptRecord transcript.ts · metrics.ts · cost.ts · eval.ts
safety L1 权限引擎：对每次工具调用做 allow / deny / ask 决策，配合沙箱 FS 守卫。作为 hook 挂到 loop 的 pre_tool_use。 PermissionEngine · PermissionDecision/PermissionEffect/PermissionInput · AskCallback · PermissionDeniedError permission.ts · sandbox-fs.ts · hooks.ts
context L1 上下文窗口管理：记忆 bundle 加载（NOVA.md>CLAUDE.md>AGENTS.md，不合并）、token 估算、阈值判断、自动压缩与微压缩。 loadMemory/MemoryBundle · estimateTokens/computeThreshold · shouldAutoCompact/autoCompact · microCompact · COMPACT_MARKER memory.ts · compact.ts · cache.ts
tools L1 内置工具集 + 注册表 + 派发器 + 不变量校验。dispatcher 用 zod 预校验输入，parse 错误转成 is_error 结果；invariants 保证每个 tool_use 必有配对 tool_result。 ToolRegistry · createDispatcher · createInvariants/InMemoryFileAccessLedger · bash/read/edit/write/glob/grep/webfetch/websearch/ask-user · todo·task 工具组 · long-running 命令管理 · skills/load-skill dispatcher.ts · registry.ts · invariants.ts · builtin/*
sandbox L1 真沙箱执行后端：封装 @anthropic-ai/sandbox-runtime（macOS Seatbelt / Linux bubblewrap）。core/tools 不直接碰沙箱 SDK，由 CLI 注入。 createSandbox · SandboxControl · CreateSandboxOptions · SandboxLogger sandbox.ts
external L1 对外集成层：MCP 服务接入（stdio/http 传输、工具名前缀映射）、slash 命令系统（文件命令加载、占位符展开）、REPL/IDE/HTTP transport。 McpManager/transportForSpec/mcpToolToHandler/MCP_TOOL_PREFIX · SlashRegistry/loadFileCommands/expandPlaceholders · transport/{repl,ide,http} mcp/* · slash.ts · transport/*
agent L2 把 core loop 与默认 hooks（权限、压缩、transcript、持久化）组装成可用 agent；构建系统提示词；按游标增量持久化 messages.jsonl。 createAgent/Agent/agent.on(point,fn) · TurnResult · buildSystemPrompt · persistMessages/loadMessages/emptyCursor agent.ts · system-prompt.ts · persistence.ts
subagent L3 把「派生子 agent」能力封装成一个可被主循环调用的工具，并为子 agent 构建专属系统提示词（按 SubAgentType 分型）。 createSubAgentTool · SUBAGENT_TOOL_NAME · buildSubAgentSystemPrompt/SubAgentType subagent.ts · system-prompt.ts
cli App 唯一 active app：终端 REPL，组装全部 10 个包，把 model/tools/permissions/transport/hooks 全部连线，是 nova 二进制入口。 repl 主循环 · context 装配 · 命令/快捷键 · 流式渲染 apps/cli/src/repl.ts · context.ts
