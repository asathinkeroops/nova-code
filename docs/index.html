三件最在乎的事

省钱、安全、灵活——不是堆功能，是一套架构

挑一个终端 AI 编程工具，开发者最在意的三件事。Nova 把它们做成了设计里的硬约束。

01 · 省钱

缓存自动命中 prefix cache

为 DeepSeek 协议级适配。消息历史只追加、绝不原地改，连写盘都做成前缀感知——服务端缓存稳稳命中，默认关掉激进压缩。

96%+ 前缀缓存命中率
02 · 安全

操作系统级沙箱 seatbelt / bwrap

所有 bash 与子进程跑在内核沙箱里，文件写入被锁死在工作区内。零配置、零摩擦，不支持的平台静默降级绝不打断你。

内核级 不可绕过的兜底
03 · 灵活

一个 .md 文件就是一项能力 declarative

放一个带 frontmatter 的 Markdown，它立刻变成运行时能力:子代理、斜杠命令、技能。不改源码、不重编译,提交到 Git 即团队共享。

0 行 代码即可扩展
Design pillars

五根设计支柱,长在一套干净架构上

统一的 hook 扩展点、严格单向的包依赖、全链路 schema 校验边界——核心循环不碰任何模型 SDK 与界面。

01

Append-only 架构

zero-cost prefix caching
每一字节历史写入即不可变,由单一 appendMessage 治理。压缩不截断历史,只追加一个 <compacted> 边界,归档完整保留。系统提示词全程冻结,缓存永不塌陷。
02

纵深防御

every layer assumes failure
模型不可靠,系统必须优雅恢复。max_tokens 是暂停而非崩溃,自动续写;每个 tool_use 都配对 tool_result;字段名写错也照跑。
truncation 续写tool_result 兜底read-before-editmtime 漂移检测
03

Agent 化一切

sub-agents as first-class
子代理是核心原语:explore / plan 只读、general 全能,双层强制权限。/goal 用独立校验子代理跑真实测试,输出 VERDICT: MET 才收工。
3 种内置类型goal 自动纠错AI 风险分级实时进度流
04

真实代码智能

LSP, not grep
目前唯一内置完整 LSP 客户端的开源 Agent。自建 JSON-RPC 传输、多语言服务多路复用,提供 IDE 级的跳转定义、类型悬停、引用查找与工作区符号——模型无需靠正则猜文件位置。
05

OS 级安全,无摩擦

safe to enable by default
封装 Seatbelt 与 bubblewrap 于内核层:写入限制、读黑名单、网络隔离、违规可见。设计成永不阻塞你——平台不支持则静默降为空操作,单条命令包装失败仍照常执行。
声明式扩展

放一个 Markdown,就多一项能力

Nova 的扩展哲学只有一句话:带 frontmatter 的 .md 文件,立刻变成运行时能力。所有外部能力都走声明式、零代码的入口,并共享同一道权限门。

  • 子代理、斜杠命令、技能——同一套模式定义
  • 兼容 Claude Code 的生命周期 Hook 与 MCP 桥接
  • 提交到 Git 即团队共享,不改源码、不重新编译
.nova/agents/reviewer.md subagent 
---
name: reviewer
description: 只读代码审查,输出 file:line 格式的问题
tools: [read, grep, glob, lsp]
readOnly: true
---
你是只读代码审查子代理。逐文件审查 diff,
按 file:line 格式报告问题,不要修改任何文件……
开发体验

不只是 CLI,更像一个开发平台

多会话热切换

/resume 交互式挑选历史会话,完整迁移 Agent 状态;/clear 开新会话而不丢旧的。

快照 + /rewind

写前 SHA-256 内容寻址快照。回滚同时还原对话与文件,并自动检测外部改动冲突。

Cron 调度

Agent 自建定时任务,支持 5m 间隔或 cron 表达式,/resume 时自动重新装载。

任务依赖图

跨会话持久化的任务图,带 blockedBy 依赖边,多个任务可并发进行中。

插件生态

nova plugin install 兼容 Claude Code 插件格式:命令、子代理、技能、Hook、MCP、LSP。

Headless JSONL 评测

nova -p --format jsonl 在 CI 里跑完整 Agent 循环,复用同一套 hook 与工具栈。
